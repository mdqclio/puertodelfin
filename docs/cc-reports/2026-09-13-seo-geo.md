### Google Maps — NO agregado (ni `sameAs` ni `hasMap`)
`https://share.google/kp1qGBd15HEmxza20` no lleva a Maps. Cadena real:
`share.google/...` → `google.com/share.google?q=...` (página JS) → `google.com/search?client=safari&hl=es-ar&kgmid=/g/1tkp64g5&q=Puerto+Delfín&shem=...&utm_source=...` (panel de conocimiento de Búsqueda) → captcha `google.com/sorry`.
Sin query string queda `google.com/search`, inútil. No inventé nada.

Opciones para que elijas (las agrego con tu OK):
1. Desde la app/web de Google Maps, "Compartir" → copiar link → me lo pasás (`maps.app.goo.gl/...` o `google.com/maps/place/...`).
2. Construir `https://www.google.com/maps?cid=<id>` a partir del place ID que ya está en el iframe del mapa del sitio (`0x8aa14c4ea5199bba` → decimal `9989726431584963514`). Es derivable, no inventado, pero no lo puse sin tu OK.
3. Usar el identificador del panel: `https://www.google.com/search?kgmid=/g/1tkp64g5&q=Puerto+Delfín` — no es Maps, tiene query string (no de tracking). Menos útil.
